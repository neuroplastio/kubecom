# 2026-10-03 — CAST-01: the screencast as an asciicast

- Agent: claude-opus-5-5
- Milestone: M5
- Did: The maintainer asked for an asciicast of the tour, for neuroplast.io's own terminal
  player, loaded from GitHub so a re-recording reaches the site without a redeploy.
  `docs/screencast/castrec` is a small recorder: tmux's `pipe-pane` hands it kubecom's pane
  (`castrec rec #{socket_path} #{pane_id}`), it opens the cast with the pane as it stands
  (`capture-pane -e` and the cursor), and each caption step marks the cast in the same tmux
  command (`run-shell 'castrec mark #{q:status-left}'`). Closing the pipe at the end of the tape
  writes `docs/screencast.cast` (asciicast v3: the pane's size and `$TERM`, output events, and
  the ten captions as markers). `make screencast` builds castrec beside kubecom.
- Recorded both, GIF and cast, against the maintainer's `k3d-kubecom-story` cluster on yaga
  through an SSH tunnel to its API port, with vhs/tmux/ttyd on the maintainer's laptop.

  check that keys are bound, not what they do: D272 opens pickers in navigation mode, so
